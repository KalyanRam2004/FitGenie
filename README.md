# FitGenie

FitGenie is an AI-powered workout and nutrition planner that provides personalized fitness recommendations based on user goals, BMI, dietary preferences, and fitness level.

## Features

- Personalized workout plans
- AI-based meal recommendations
- BMI calculation
- Progress tracking
- Weekly and monthly goal forecasting
- Responsive UI

## Tech Stack

Frontend:
- React.js
- HTML
- CSS
- JavaScript

Backend:
- Flask
- Python

Machine Learning:
- Scikit-learn

Database:
- SQLite

## Installation

git clone https://github.com/<your-username>/FitGenie.git

cd FitGenie

Install frontend dependencies

npm install

Install backend dependencies

pip install -r requirements.txt

Run the frontend

npm start

Run the backend

python app.py
